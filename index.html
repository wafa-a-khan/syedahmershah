Syed Ahmer Shah, "Ahmer" to everyone, is a software engineer from Hyderabad, Sindh. He studies Software Engineering at HITMS while following a three-year Advanced Diploma at Aptech Pakistan, a pairing of theory and hands-on practice that covers programming, web development, databases and full software design.

He builds full-stack web apps and APIs, uses AI tools such as Claude Code, GitHub Copilot and Cursor to move faster, and says plainly that the thinking stays human. His aim is to grow into a strong full-stack developer and leave behind work that lasts.

Outside the editor he writes: more than forty articles on seven platforms, including engineering logs and case studies. He works remotely for clients worldwide on Pakistan Standard Time.

University admission and examination portal

Real features in a professional team, covering a student's whole journey from registration to exam slip. Built with PHP, Laravel, MySQL, JavaScript, Tailwind CSS and Bootstrap, with Git and GitHub for version control.

Ahmer Institute of Technology

He later rebuilt the portal on his own and took it further: 31 tables with reporting views, student, admin, staff and teacher portals, race-safe approvals, CSRF protection, a nonce-based CSP and rate limits. Source on GitHub
